# Repository Instructions

## Git Workflow

- After editing code, tests, documentation, configuration, or other project files for a user request, run the relevant verification and create a Git commit in the same turn before reporting completion.
- Stage and commit only files related to the current task. Never include unrelated user changes.
- Do not push commits unless the user explicitly requests a push.
- If verification or commit creation is blocked, report the blocking reason clearly instead of claiming the task is complete.
- If the user explicitly asks not to commit a particular change, follow that instruction for that change.
